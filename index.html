READ THIS

Downloading the map does not automatically update your game. You must copy the file into your game folder yourself.

You must start a brand new save file to see your map changes in-game. Loading an existing save will not reflect the new map.
Windows
  1. Download horsey.tmx using the button below.
  2. Open your Steam game folder:
    C:\Program Files (x86)\Steam\steamapps\common\Horsey Game\Resources
  3. Back up your existing horsey.tmx before continuing — rename it to horsey.tmx.bak or copy it somewhere safe.
  4. Replace the existing horsey.tmx with the one you downloaded.
  5. Start the game and enjoy your changes.
macOS
  1. Download horsey.tmx using the button below.
  2. Open Finder and navigate to your Steam game folder:
    ~/Library/Application Support/Steam/steamapps/common/Horsey Game
  3. Right-click Horsey Game.app and choose Show Package Contents.
  4. Navigate into Contents/Resources/.
  5. Back up your existing horsey.tmx before continuing — rename it to horsey.tmx.bak or copy it somewhere safe.
  6. Replace the existing horsey.tmx with your downloaded file.
  7. Start the game and enjoy your changes.
Linux
  1. Download horsey.tmx using the button below.
  2. Navigate to your game folder:
    ~/.steam/steam/steamapps/common/Horsey Game/Resources
  3. Back up your existing horsey.tmx before continuing — rename it to horsey.tmx.bak or copy it somewhere safe.
  4. Replace the existing horsey.tmx with your downloaded file.
  5. Start the game and enjoy your changes.
